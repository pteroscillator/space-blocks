# Space Blocks

An arcade game: steer a small ship up through falling blocks, collect fruit and shields, with its own generated music. Arrow keys and Space on a computer, on-screen buttons on a phone.

Live: https://pteroscillator.github.io/space-blocks/

Browsers tested: Safari and Firefox on macOS, Safari on iPhone

Web Audio behaves differently on Safari and iOS. On iOS, the sound plays even with the silent switch on (Safari 16.4 or later).
